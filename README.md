# STM32 Learning Platform

Минимальный программный каркас аппаратно-программной
обучающей платформы для микроконтроллеров STM32.

## Технологии

- Go 1.23
- SQLite
- modernc.org/sqlite
- GitHub Actions

## Требования

- Go версии 1.23 или выше
- Git
- Доступ к интернету для загрузки зависимостей

## Установка

Клонировать репозиторий:

    git clone <URL_РЕПОЗИТОРИЯ>
    cd stm32-learning-platform

Загрузить зависимости:

    go mod download

## Запуск тестов

Выполнить все модульные тесты:

    go test -v ./...

Запустить тесты с проверкой гонок данных:

    go test -race ./...

Проверить форматирование:

    gofmt -l .

## Реализованные тесты

1. TestNewStore — проверка создания хранилища.
2. TestSaveAndGetConfig — проверка сохранения и чтения конфигурации.
3. TestSaveInvalidJSON — проверка отклонения некорректного JSON.
4. TestSaveWithoutName — проверка обязательности имени.

## Непрерывная интеграция

GitHub Actions автоматически запускает тесты и проверку
форматирования при отправке изменений в main/master
и при создании pull request.

Результаты проверки доступны во вкладке Actions
репозитория GitHub.

## Текущий статус

Реализован минимальный модуль локального хранения
конфигураций микроконтроллеров.

Интерфейс Wails, генератор прошивок HAL/CMSIS,
поддержка RTOS и интеграция с аппаратной платой
пока не реализованы.
